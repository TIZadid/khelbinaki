# Setup & Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Go from an empty folder to a tested, deployed skeleton: a Hono Worker with a D1 `posts` table and a `/health` endpoint, and a themed Vite + React landing page, both live on Cloudflare's free tier.

**Architecture:** Two independent npm packages in one git repo: `api/` (Cloudflare Worker + Hono + D1 migrations, tested inside the Workers runtime with `@cloudflare/vitest-plugin`) and `web/` (Vite + React + Tailwind v4 with shadcn-style tokens and `motion` animation primitives, tested with Vitest + Testing Library in jsdom). Nothing talks to anything else yet; feature plans wire them up.

**Tech Stack:** Node 22 (via nvm), wrangler 4, hono 4, D1, vitest 4.1 (api) / latest vitest (web), vite 8, react 19, tailwindcss 4, motion 13, TypeScript.

**Spec:** `CLAUDE.md` (product rules) + `docs/superpowers/specs/2026-09-21-khelbinaki-design.md` (design decisions). Read both.

## Global Constraints

- Zero hosting cost: free tiers only; no paid services, no paid APIs, no per-message costs.
- No login/accounts. No in-app messaging.
- Stay inside Cloudflare (Workers, D1, Pages, Turnstile). Do not introduce Supabase/Firebase/etc.
- Node: run `nvm use` in the repo root (pins 22 via `.nvmrc`). Never change the machine-wide nvm default.
- `api/` must use `vitest@^4.1` (peer requirement of `@cloudflare/vitest-plugin`). Do not install vitest 5 there.
- Timestamps: `start_datetime` stored as UTC `toISOString()`; feed compares against a bound ISO parameter, never `datetime('now')`.
- Colors: use the shadcn token names and values from spec section 4 (`--primary: #a6d421`, etc.). Dark-only.
- All animation via `motion` (`motion/react`) and must respect `prefers-reduced-motion`.
- Commit messages end with the line `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.

```tsx
import { motion, useReducedMotion } from "motion/react";
import type { ReactNode } from "react";

export function FadeUp({
  children,
  delay = 0,
  className,
}: {
  children: ReactNode;
  delay?: number;
  className?: string;
}) {
  const reduce = useReducedMotion();
  return (
    <motion.div
      className={className}
      initial={reduce ? false : { opacity: 0, y: 16 }}
      whileInView={{ opacity: 1, y: 0 }}
      viewport={{ once: true, margin: "-40px" }}
      transition={{ duration: 0.5, delay, ease: [0.22, 1, 0.36, 1] }}
    >
      {children}
    </motion.div>
  );
}
```

```tsx
import { type MouseEvent, type ReactNode, useRef } from "react";
import { cn } from "@/lib/utils";

export function GlowCard({
  children,
  className,
  highlighted = false,
}: {
  children: ReactNode;
  className?: string;
  highlighted?: boolean;
}) {
  const ref = useRef<HTMLDivElement>(null);

  function onMouseMove(e: MouseEvent<HTMLDivElement>) {
    const el = ref.current;
    if (!el) return;
    const rect = el.getBoundingClientRect();
    el.style.setProperty("--mx", `${e.clientX - rect.left}px`);
    el.style.setProperty("--my", `${e.clientY - rect.top}px`);
  }

  return (
    <div
      ref={ref}
      onMouseMove={onMouseMove}
      className={cn(
        "glow-card relative rounded-lg border p-5 transition-colors",
        highlighted
          ? "border-primary bg-primary text-primary-foreground"
          : "border-border bg-card/80 text-card-foreground backdrop-blur hover:border-primary/40",
        className,
      )}
    >
      {children}
    </div>
  );
}
```
