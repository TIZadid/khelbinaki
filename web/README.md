# Khelbi Naki — web

Vite + React frontend, served as a Cloudflare Worker with static assets
(`wrangler.jsonc`). Pushes to `main` deploy to https://khelbinaki.zlabz.workers.dev.

```
nvm use
npm install
npm run dev     # http://localhost:5173
npm test
npm run build
```

See the repo root `CLAUDE.md` for project context.
